CAHIER DES DIACRES — EPMB AHOSSOUGNETA — V4

Cette version ajoute la base PWA : installation sur Android, icône et fonctionnement hors connexion après mise en cache.

IMPORTANT : pour que le bouton « Installer l'application » et le Service Worker fonctionnent, le dossier doit être servi par HTTPS (par exemple via un hébergement web). Ouvrir index.html directement comme un fichier ne suffit pas pour activer toutes les fonctions PWA.

Le cahier conserve actuellement ses données dans le stockage local du navigateur/appareil.
La synchronisation cloud automatique et le PIN sécurisé seront ajoutés dans une prochaine étape.
